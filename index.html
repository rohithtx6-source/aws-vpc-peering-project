AWS VPC Peering Project

Designed and tested private network connectivity between two Amazon VPCs using AWS networking services.

Project showcase by Rohith Thommandru

Project Overview

This project demonstrates how to connect two Virtual Private Clouds (VPCs) in AWS using VPC Peering, configure subnet route tables, and verify private IP connectivity between EC2 instances.

Cloud provider: Amazon Web Services (AWS)

Region: Asia Pacific (Sydney)

Network Architecture

VPC A

10.10.0.0/16

Public subnet: 10.10.1.0/24

Private subnet: 10.10.2.0/24

EC2 App A: 10.10.2.202

VPC Peering

Connection: ewb-a-b-peer

Purpose: private communication between VPC A and VPC B.

VPC B

10.20.0.0/16

Private subnet: 10.20.1.0/24

EC2 App B: 10.20.1.170

Architecture summary based on the implemented project configuration.

Implementation

  • Created two separate VPCs with non-overlapping CIDR blocks.
  • Created public and private subnets.
  • Attached an Internet Gateway for the public subnet in VPC A.
  • Established a VPC Peering connection.
  • Added routes to the remote VPC CIDR blocks.
  • Configured EC2 instances and security rules for connectivity testing.

Connectivity Test Results

Successful at the time of testing: both directions.

App A → App B

ping -c 4 10.20.1.170

4 packets received, 0% packet loss.

App B → App A

ping -c 4 10.10.2.202

4 packets received, 0% packet loss.
